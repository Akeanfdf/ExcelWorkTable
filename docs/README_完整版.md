# Excel 工作流与批量表单工具

## 功能简介

- **可视化工作流**：对 xlsx / xls / csv 做「导入 → 多步操作 → 导出」；支持多文件、步骤链、保存/载入 `workflow.json`、多表套用同一套步骤、内置说明书与帮助。
- **线性界面常用能力**：数据整理（标准化、去重、空值、筛选、排序、选列、替换、重命名）、合并文件、填充 Excel 模板、写出 xlsx、ZIP 打包；引擎侧还可扩展合并/透视/PDF/打印/文件批处理及可选 AI、PDF 表格提取等（见 `excel_workflow/nodes`）。
- **批量表单生成器（旧版）**：按数据源**每一行**填入模板单元格，批量生成多份 Excel，配置存 `mapping_config.json`。

| 程序 | 典型用途 |
|------|----------|
| 工作流主程序 | 规则复杂、多步、需复用流程或批量处理多张表 |
| Tk 生成器 | 规则固定、逐行套打模板即可 |

---

面向 **Excel / CSV 表格** 的桌面工具集：一条是「多步骤处理 + 可复用流程」，另一条是「按行套打模板」。仓库地址：<https://github.com/Akeanfdf/ExcelWorkTable>

## 一、Excel 可视化工作流（主程序）

用 **「导入 → 操作 → 导出」** 把多张表当成一条流水线处理：每一步在界面上选好参数并执行，结果留在内存或缓存里，最后再统一导出。适合日常整理数据、套模板出表、多文件同一套规则批处理。

### 使用方式上的能力

- **多文件导入**：拖放或选择多个 xlsx / xls / csv；也可按文件夹扫描后勾选。列表里**第一张表为主表**，预览、列名联想、筛选默认值等都跟主表走。
- **步骤可叠加**：在「操作」页左侧按分类点功能，右侧时间线里填参数并点「应用」，形成一条**步骤链**；顺序执行，便于重复劳动一次配好、以后改数再跑。
- **多表同一套步骤**：多张表都载入后，可对**每一张表**依次重放整条步骤链（列名与条件需在各表上都能成立）。
- **流程可保存 / 复用**：把当前步骤链存成 `workflow.json`（v2），下次「导入流程」即可按模板重放；也可备份给他人用。
- **与旧版配置衔接**：若以前用过根目录下的 `mapping_config.json`，可在导入阶段读取，用于预填「填充模板」等参数。
- **导出阶段**：勾选要落盘的内容（如处理后的主表、中间生成的文件等），选目录与格式后写出或复制；支持一键「批量导出」勾全项。
- **说明书内置**：工具栏可打开全文说明；各按钮旁的「?」有对应功能的详细解释。

### 操作页里直接提供的功能块（线性界面）

| 分类 | 功能 |
|------|------|
| 数据操作 | 格式标准化、去重、空值填充、筛选行、排序、选列/删列、查找替换、列重命名 |
| 结构操作 | 合并文件、填充模板（把列数据写入指定 Excel 模板单元格） |
| 格式与输出 | 写出 xlsx、打包 ZIP |

### 底层还包含的节点能力（与上表同一套引擎，部分在扩展/图编排场景使用）

- **数据源**：Excel 读取、CSV 读取、文件夹监听、计划触发等  
- **清洗**：去重、空值填充、格式标准化、列重命名  
- **变换**：表达式列、日期格式化、数值换算、列拼接、类型转换  
- **筛选与拆分**：行过滤、分组字典、抽样、条件分支  
- **合并**：纵向合并、表关联、透视  
- **模板**：模板填充、多模板路由  
- **导出**：写出 Excel、导出 PDF、ZIP 打包、打印  
- **文件运维**：批量重命名、移动、按规则分目录、归档复制  
- **控制**：逐行透传、Try 透传、输出日志  
- **AI / 文档**（按需配置密钥）：PDF 表格提取、AI 字段识别、AI 映射建议

## 二、Excel 批量表单生成器（旧版 Tk 工具）

专注一件事：**把「数据源表」的每一行，填进「模板 Excel」里预留的单元格**，按行生成多份独立文件。

- **文件配置**：选数据源、模板、输出目录，以及用于文件命名的列、工作表名。  
- **字段映射**：配置「数据列 → 模板单元格」对应关系。  
- **生成与日志**：查看摘要、进度与运行日志。  

配置会保存在项目目录下的 `mapping_config.json`，适合规则固定、不需要多步编排的场景。

## 环境与运行（简表）

| 程序 | Python | 启动 |
|------|--------|------|
| 可视化工作流 | 3.10+ | `py -3.11 -m pip install -r requirements-workflow.txt` 后执行 `py -3.11 -m excel_workflow.app` 或 `py -3.11 run_workflow.py` |
| Tk 批量生成器 | 一般 3.x 即可 | `pip install openpyxl pandas` 后 `python main.py` |

打包：工作流用 `pyinstaller Excel工作流.spec`；旧版用 `Excel批量表单生成器.spec` 或按旧 README 中的一行 `pyinstaller` 命令。

更细的安装排障、缓存目录、AI 密钥等说明见 **`examples/运行说明.txt`** 与 **`examples/templates/mapping_migrate.md`**（旧映射迁移）。
