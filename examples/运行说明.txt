Excel 可视化工作流 — 简要说明
================================

快速开始（团队同事）
--------------------
  1) 安装依赖（Python 3.10+）：在同一解释器下执行
       py -3.11 -m pip install -r requirements-workflow.txt
     或使用你的安装路径，例如：E:\Python311\python.exe -m pip install -r requirements-workflow.txt
  2) 启动：py -3.11 -m excel_workflow.app
  3) 主窗口为「线性流程（导入 › 操作 › 导出）」：顶部三步进度（不可跳步）— 先完成「导入」（文件/文件夹勾选）后自动进入「操作」；左侧块状按钮追加步骤，右侧时间线内填参数并点「应用」执行（与节点 runner 相同逻辑，结果进缓存目录）；底栏「导出文件」进入导出页；导出成功后可选择将本次步骤保存为 workflow.json（v2）。亦可点「保存流程」随时保存。支持「导入旧版 mapping_config.json」并预填「填充模板」参数。缓存与模板默认放在「非 C 盘」首个可用盘符下的 .excel_workflow（如 D:\\.excel_workflow\\staging）；若只有 C 盘或需指定路径，请设置环境变量 EXCEL_WORKFLOW_DATA_ROOT（例如 E:\\MyCache），程序会在其下创建 staging、simple_templates、recent.json。
  4) 主窗口仅保留线性流程；工具栏「?」可打开《功能说明书》全文。各按钮旁「?」或「本页功能说明」可查看单项说明。
  5) 日志在窗口底部 Dock；节点图画布已从本程序主窗口移除，runner 仍由 `excel_workflow.nodes` 在启动时注册供线性流程调用。
  6) 内置 workflow JSON 仍位于 examples/templates/（供参考或脚本 tools）；画布编排若需 NodeGraphQt，请在仓库内单独脚本中引用同套 nodes。

0. 故障：sys.prefix 指向「本仓库路径」、报 encodings 找不到
   若运行 py -3.11 时出现：
     stdlib dir = 'E:\excel...\Lib'
     ModuleNotFoundError: No module named 'encodings'
   说明解释器把「安装根」当成了 E:\excel表格（下面没有完整 Lib\encodings），与 pip 无关。

   A) 若 echo $env:PYTHONHOME 为空，仍出现该错误，则多半不是 PYTHONHOME，请依次排查：
   b) 检查是否误激活了坏虚拟环境（变量仍可能来自「用户/系统」层）：
        [Environment]::GetEnvironmentVariable('VIRTUAL_ENV','User')
        [Environment]::GetEnvironmentVariable('VIRTUAL_ENV','Machine')
      若有值指向本仓库，在「系统属性 → 环境变量」里删除 VIRTUAL_ENV / 关闭错误 conda 环境。
   c) 运行仓库根目录脚本（对比「在 C:\ 下启动」与「在本目录启动」的 prefix）：
        powershell -ExecutionPolicy Bypass -File .\diagnose_python.ps1
   d) 用资源管理器检查是否存在（若内容把 home 指到本仓库，应改正或删除后重装 Anaconda）：
        D:\anaconda3\pyvenv.cfg
        D:\anaconda3\python311._pth 或 python._pth
   e) 根治：从 https://www.python.org/downloads/ 安装 3.11/3.12 到**非 C 盘**纯英文路径（如 D:\Python311、E:\Python311；安装向导里改目标文件夹），用：
        E:\Python311\python.exe -m pip install -r requirements-workflow.txt
      避免使用已损坏的 D:\anaconda3\python.exe。

   若 echo $env:PYTHONHOME 有值：本会话 Remove-Item Env:PYTHONHOME 后重试；并在系统环境变量里删除 PYTHONHOME。

   可选：install_workflow_deps.ps1 仅清除本会话 PYTHONHOME/PYTHONPATH，对「未设置 PYTHONHOME 仍错」无效。

   f) 若确认 D:\anaconda3 中 Python 已损坏：见 examples\Anaconda修复或卸载.txt ，或运行交互脚本
        powershell -ExecutionPolicy Bypass -File .\uninstall_anaconda.ps1
      （优先官方卸载；可选清理用户 PATH；整目录删除需输入确认语。）

1. 安装（必须用 Python 3.10+，不要用系统自带的 Python 3.7）
   若已安装多个版本，推荐用启动器指定 3.11/3.12：
   py -3.11 -m pip install -r requirements-workflow.txt
   （requirements-workflow.txt 已改为纯英文注释，避免 pip 在 GBK 下读文件报 UnicodeDecodeError。）

2. 启动（与上一步同一解释器）
   py -3.11 -m excel_workflow.app
   或 py -3.11 run_workflow.py
   若仍用默认 python 且为 3.7，会提示升级；PySide6 不支持 3.7。

3. 从旧版 mapping_config.json 迁移
   工具栏「导入 mapping_config」→ 自动生成「Excel 读取」「模板填充」节点并连线。
   请在节点上补全路径（若 JSON 中为绝对路径一般会自动填入）。

4. AI 密钥（可选）
   将 secrets.example.json 复制到：
   Windows: C:\Users\<用户名>\.excel_workflow\secrets.json
   填写 api_key；也可设置环境变量 OPENAI_API_KEY。

5. 打包 exe
   pyinstaller Excel工作流.spec

6. 原 Tk 单工具
   python main.py  （仍可单独使用）
